# さっきのタブ — MRU

今のウインドウで閲覧した直近8件のタブを、横並びのカードから切り替えられるChrome拡張です。

## 導入方法

1. GitHubの **Code → Download ZIP** からダウンロードし、ZIPを展開します。
2. Chromeで `chrome://extensions` を開きます。
3. 右上の **デベロッパーモード** をオンにします。
4. **パッケージ化されていない拡張機能を読み込む** を押し、展開したフォルダー内の **`extension` フォルダー** を選びます。
5. 必要に応じて、拡張機能メニューからツールバーに固定します。

更新するときはファイルを新しいものに置き換え、拡張機能の画面で再読み込みしてください。

## 使い方

| 操作 | キー・方法 |
| --- | --- |
| 一覧を開く | Mac: **Control＋Q**、または拡張アイコンをクリック |
| 選択 | Tab／矢印キー（Shift＋Tabで逆順） |
| 確定 | Enter、またはカードをクリック |
| 取消 | Esc、×、または背景をクリック |

Windows／Linuxでは **Ctrl＋Shift＋Y** で開きます。キーを変更する場合は `chrome://extensions/shortcuts` を開いてください。

## 注意点

- 閲覧済みのタブだけを表示します。初回やChromeの再起動後は、表示中のタブから記録を始めます。
- プレビューがなくても、閲覧済みならタイトルのカードを表示し、切り替えられます。
- **Ctrl＋Tabでの起動には対応していません。**
